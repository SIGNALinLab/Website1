# SIGNAL Lab — GitHub Pages website

Static GitHub Pages research-lab website. Run locally with `python -m http.server 8000`. Edit configuration in `assets/data/config.json`, publications in `assets/data/publications.json`, projects in `assets/data/projects.json`, people in `assets/data/people.json`, and equipment in `assets/data/equipment.json`.

## Banner color
All page banners intentionally use one unified SIGNAL blue–cyan luminous palette. Page-specific scientific illustrations and motion remain distinct.
