# SIGNAL Lab website

Static GitHub Pages website. Run locally with `python -m http.server 8000`. Configuration is in `assets/data/config.json`; publications/projects/people/equipment use JSON data files. The current release intentionally leaves canonical URL, People, and Equipment unverified until owner-confirmed data is available.

## Banner palette
All page banners use the same blue–cyan luminous palette as the homepage. Page-specific scientific illustrations remain unchanged.
