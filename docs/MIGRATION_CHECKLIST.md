# Content migration checklist

## Projects
- [ ] Export/copy each current project title exactly.
- [ ] Preserve technical descriptions and factual claims without marketing rewrites.
- [ ] Map verified status, team, lead, objective, outcomes, technologies, media, publications, code, datasets, collaborators, and funding into `assets/data/projects.json`.
- [ ] Do not create entries for missing or ambiguous source content.

## People
- [ ] Copy the complete current staff roster.
- [ ] Group into Leadership, Researchers, Current Students, Collaborators, Alumni as appropriate.
- [ ] Preserve names, roles, and factual bios.
- [ ] Add portrait alt text and verified profile links.
- [ ] For each alumnus, add a recommendation URL only if a real public document exists and publication is approved.

## Contact and identity
- [ ] Confirm exact lab room/building.
- [ ] Confirm lab-specific email/phone, if different from the verified PI institutional email.
- [ ] Confirm final domain and social links.
