# Owner verification required before public launch

The repository deliberately avoids guessing the following items:

1. **Production URL** — set `canonicalBaseUrl`, populate `sitemap.xml`, and replace `YOUR-DOMAIN` in the LaTeX templates once the actual GitHub Pages/custom-domain URL is known.
2. **People roster** — the current public page remains fail-closed until the lab confirms the roster/profile data.
3. **Equipment inventory** — the current public page remains fail-closed until actual inventory, ownership/status, access, and location details are verified.
4. **External Google Form** — manually confirm the configured form is shared to the intended audience and contains the intended privacy/consent language and application disclaimer.
5. **Room-level directions** — the site intentionally uses the verified broader College of Engineering, Qassim University location and does not assert an unverified room number.
6. **Recommendation records/documents** — publish only intentionally public validation metadata/documents; do not commit confidential recommendation prose or sensitive student information.
